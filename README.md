A simple and fun Snake Water Gun game built using Python. This is my first project. This project is inspired by Rock-Paper-Scissors where you play against the computer using Snake, Water, and Gun choices.

## 🧠 How It Works
- Snake drinks water
- Water damages gun
- Gun kills snake
- Player chooses one option
- Computer randomly selects one
- Winner is decided based on rules

## 🎮 Game Rules
- Snake 🐍 = 1
- Water 💧 = -1
- Gun 🔫 = 0

## 🚀 Features
- Random computer choice
- User input system
- Dictionary-based mapping
- Win/Lose/Draw logic
- Beginner-friendly Python project

## 🛠️ Technologies Used
- Python
- Random module
